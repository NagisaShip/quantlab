# 修复与剩余研究室流程复测

日期：2026-10-26。模型仍为 OpenCode Go `deepseek-v4.1-flash`。这是原始 [体验记录](README.md) 的后续；原始响应与失败证据保留，没有覆盖成成功结果。

已完成本轮发现的具体缺陷修复，以及剩余研究室的归档闭环。所有研究资产都保留为候选或草稿，没有启用实盘。

## 无限计量

- 测试工作区七项限额全部设为 `null`，包括 token、调用次数、回测、CPU、优化组合、下载和存储。
- 产品默认限额也改为 `None`：默认持续计量、不按用量拒绝；管理员仍可为指定工作区显式设限。
- 最终账本累计 **138次模型调用、4,732,869 token**，已超过原来的200万 token 上限；所有用量项 `limit=null`、`exhausted=false`。
- 单个用户任务显式配置的工具调用预算仍有效。这是执行边界，不是计量收费上限；持久化与普通研究室均累计计划后续回合，批量工具也不能越界。

证据：[限额变更](unlimited_usage_limits.json)、[最终计量](verified_final_usage.json)。以上是本地平台账本，未独立核对供应商账单，不代表供应商不存在自身限额。

## 修复清单

| 发现 | 改动 | 验证依据 |
|---|---|---|
| 年化/累计、毛/净收益和换手计费混淆 | 报告新增 `metric_contract`、`ls_total_return`；注明半L1展示、完整L1计费，并给模型返回口径 | 真实因子会话纠正原错误；净值与累计收益一致性回归 |
| ridge基线解释成线性模型 | 修改提示词，工具返回实际 `baseline`、`baseline_name`；历史报告读取时补充合同 | 最终模型会话分别读取两份原报告，基线解释正确 |
| “零假设噪声地板”等无依据统计结论 | 共享研究解释约束明确禁止该推断，要求区分实测差距与未验证假设 | 最终因子会话撤回推断，并给出正确绝对/相对差距 |
| 研究准入被当作可交易/可上线 | 保留 `admitted` 的研究语义，增加独立启用资格与原因；校验费后收益、合成数据、项目目标、显著性/漂移；前端不再显示“可上线” | 三类不合格资产的真实启用请求均返回409 |
| 保存候选却自动启用 | `save_work` 默认 candidate；策略仍保存草稿；历史测试中的错误active已降为candidate | 最终库存无active，归档事件全部candidate或draft |
| 保存不同版本覆盖同一资产 | 按归档版本绑定资产ID，同版更新、异版另存 | 两个组合、两个模型各有独立ID；回归检查两版归档无覆盖 |
| 无恢复工具，只能重写/重训来归档 | 增加 `restore_version` 工具，直接恢复代码及原评估证据，不重算；纳入编辑权限分类 | 最终模型仅4个工具调用，版本数不增加 |
| 模型自行换币池、区间、周期或标签 | 目标/市场工具校验研究范围；更换标签或持有期需要研究者提交新规格；显式提供的新市场参数仍可设置 | 池扩张、标签更换被回归测试阻止 |
| 计划为默认目标持续追加试验，旧计划被新问题触发 | 已声明步骤完成即结束，如实记录未达标；普通新请求先暂停旧计划 | 已完成但未达标、不继续旧实验两项回归通过 |
| 工具上限按内部回合重置，批量调用可能越界 | 普通回合共享用户消息预算；持久化回合从Journal计数；耗尽时暂停计划 | 普通、批量与持久化计划预算回归均通过 |
| 模型失败降级会覆盖风控配置 | 已有代码/规格时保留版本、参数和评估，不生成默认替代；API增加partial/failed及错误投影，预算耗尽单独标注 | 失败注入确认30%上限、目标波动和回撤规则不变 |
| 减仓虚增有效持仓数 | 按总敞口归一化风险资产权重后计算，现金不计入；同步说明 | 真实六币风控组合平均敞口0.6389，有效持仓5.6528；不会出现原先21.97 |
| 手写止损误报“没有任何止损” | 静态规则改为“未识别到平台原生保护止损”，明确自定义清仓需验证 | 手写止损回归不再出现无依据断言 |
| 中文加下划线项目名无法保存 | slug生成时同时清理前后连字符与下划线 | 原名成功保存；中文、下划线等六类名称回归通过 |
| 初版测试脚本组合约束层级写错 | 后续脚本已使用 `config.constraints`、`rebalance`；原始错误输入仍保留 | 30%约束的补测证据保留，不归因于产品引擎 |

“研究通过”仍不是独立实盘批准。统计上有用但费后交易表现不佳的因子/模型可以作为候选保留，不能因为研究检查通过就启用。没有通过修改收益数据、降低目标或扩大币池来制造成功。

## 保留的研究边界

本轮修复并验证的是已发现的具体程序缺陷与解释约束，不能保证模型未来所有文字永不出错，也没有把负收益策略“修成盈利”。多年独立样本、历史成分/退市验证、实盘成交校准、容量与长期账实对账仍需另行采证；这些未验证事项没有被写成已经具备的专业交易能力。
