# QuantLab研究工作流方案与实施边界

更新：2026-10-20。工作流加入原有QuantLab研究导航、主题和权限体系；不提交Git。此次交付是可执行的通用研究工具及分类基线，不等同于已完成作业要求的六模型实证和汇报材料。

## 产品与模块

一张函数卡片对应一个可查看的Python源码文件：字面量`NODE`声明接口，`execute(ctx, inputs, params)`实现计算。注册表从源码生成GUI端口、参数表单、Agent工具目录与独立运行包，避免维护多套计算实现。

模块分为契约与静态检查、不可覆盖的版本注册、DAG运行与工件、工作区服务、HTTP/Agent适配、导出器和React画布。HTTP与Agent调用同一个工作区服务；执行复用平台已有队列、配额、任务取消和运行记录。自定义代码在独立子进程运行，有超时及取消边界；它属于可信Python扩展，独立进程不构成恶意代码沙箱。

画布采用React Flow，复用QuantLab颜色、字体和控件：空白处拖动平移、滚轮缩放、Shift框选、缩略导航、连线与键盘删除；步骤视图显示同一工作流。左侧函数库，右侧参数/代码/数据日志检查器；卡片翻转显示函数及依赖，端口位置保留。连线可插入兼容处理卡片，支持撤销重做和子流程封装/展开。

## 接受的八项设计

| 设计 | 实现与验收口径 |
| --- | --- |
| 参数来源明确 | 参数手填、默认值与输入绑定分别显示；运行记录保存解析后的实际参数和输入工件哈希。 |
| 接口升级可审阅 | 发布前检查语法、接口与源码差异；同名同版本代码不可覆盖；替换版本保留旧连接，失效端口标红，由自检阻止运行。 |
| 中间结果可调试 | 内容寻址工件、输入与文件哈希缓存；执行到指定节点；固定历史输出及使用历史输入重放，仅允许调试模式。 |
| 语义契约 | 校验具名端口、类型、用途及参数/输入输出schema；训练、验证、测试分端口，阻止测试用途进入训练输入。单位、时间可用性和实体ID体系仍需领域卡片明确实现检查，不能仅凭table类型认为合规。 |
| 检查也可复用 | 全链路/目标节点静态检查；表格完整性、非空与唯一键检查卡片可进入数据链路。静态通过不代表执行或实证有效。 |
| Agent可追溯 | Agent通过同一目录、检查、修订和运行服务操作；保存来源、修订版本、精确函数哈希和执行记录。 |
| 实例与发布分开 | 实例参数和位置独立；复制为新的kind后自定义；公共版本不可覆盖；可复用子图有显式边界，展开后逐卡片编辑。 |
| 实验与证据 | 成功、失败、被阻断分支分别显示；保留工作流修订、种子和环境；历史实验可查看、旧内容恢复时生成新修订。支持提交1—8个不同种子，每次快照保留相同修订和独立运行，逐项查看结果进行比较；批量种子实验按独立运行保存，不能用一次成功代替稳健性结论。 |

## 自定义卡片

规范见《自定义卡片规范.md》。用户在界面查看、复制、编辑源码，预览差异后发布新版本。需声明全部第三方库、文件参数、输入输出和研究用途。复合卡片以`NODE.subflow`保存内部定义与边界；固定分派函数不可私自改写，算法修改通过展开子流程或编写普通函数卡片完成，避免界面显示的代码与实际执行不一致。

## 完整离线导出

ZIP包含工作流、实际使用的卡片源码与版本、运行器、显式文件、依赖声明、包含传递依赖的wheel、带SHA256的requirements.lock和启动脚本。依赖下载失败、缺少数据、声明需联网或没有可移植实现时，拒绝生成标为完整的包。文件输入没有静默省略的选项。

下载时平台可以联网取得依赖；解压后安装使用`--no-index --require-hashes`，执行不调用QuantLab服务。用户机器需有匹配的Python解释器，二进制依赖要求相同Python主次版本、系统和CPU架构。包不附带解释器，不能承诺一个wheel包在所有系统通用。哈希检验用于检查完整性，不能证明代码作者身份。

## 首批函数与后续研究

首批提供CSV导入、CSV结构审计、共享配置、字段筛选、质量检查、年度切分、描述统计、逻辑回归、预测、分类评价与证据汇集，并提供CSV研究和年度分类模板。

本次不自动把商业数据库原始文件写入项目仓库。CSMAR异常CSV需先使用已有来源适配器规范化，再作为文件输入导入；财务表大于默认行数时显式提高max_rows，不能静默截断。原数据复查结论仍有效：DeclareDate不是首次公告日；未上市企业早期历史与利息费用覆盖仍有限。上述为初始路线。现已完成领域卡片、六模型与LoRA实验及Word/PPT；实际方法与无法满足严格时点标签的限制见《供应链信用研究复现》。
