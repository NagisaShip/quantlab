# 研究工作台界面与 Agent 产物

更新：2026-10-21。

## 使用入口

- 研究工作流：`#/workflows`。默认展示研究路径，顶部始终保留最近一次结果入口。
- 设置 → 插件管理：`#/settings/plugins`。
- 原有流程、函数版本、运行记录、代码工作台、图表和网络编辑器继续使用同一服务。

## 界面与交互

研究路径、实验与比较、研究成果成为三个工作视图。模块库可按研究任务、最近使用和常用模块浏览；常用与最近记录按工作区存放。画布保留原有位置、撤销重做、端口和子流程能力。

结果面板位于画布下方，打开时压缩画布并滚动到结果。可拖动或用键盘调高，切换节点的输入、输出、日志。表格显示分页范围，支持当前预览页筛选与完整 JSON/CSV 下载；筛选不会改变原始产物。图表可直接查看、放大和下载，生成的数据文件可继续预览。数据输出可直接创建下游图表。

修改参数、函数版本、输入绑定、连接或随机种子后，受影响节点及下游标为结果待更新；修改标题、显示位置不使计算结果过期。最终缓存是否可复用由运行器根据实际指纹检查，包括文件变化。

参数引用可选择已连接的上游输入及字段，展示类型和已运行样例；仍保留高级路径输入。模块的配置与运行证据分别呈现。

实验网格使用模块、参数、候选值表单；滚动窗口使用切分模块、训练截止和验证截止表单。高级 JSON 仍可使用。提交前预检并冻结预览计划，修改后必须重新预检。每次最多八个组合，保留失败项，支持指标比较和相对首项的差值，不自动选出最优模型。

研究成果可按当前研究、全部研究、运行和关键词查找，覆盖最近 500 次平台运行，并显示独立图表预览。产物可定位来源节点或引用到研究笔记。笔记记录运行引用和工件哈希，保存有版本冲突检查，可预览和导出 Markdown。

## Agent 与对话

平台 Agent 和 GUI 共用目录、版本、运行、产物和插件策略。已有创建、提案、修改、检查和实验工具继续可用，补齐或增强了：

| 工具 | 能力 |
| --- | --- |
| `workflow_inspect` | 读取当前或指定历史修订、指定运行及节点证据 |
| `workflow_run` | 正式运行、目标节点、种子和修订；可用历史运行输入调试 |
| `workflow_cancel` | 取消工作流任务 |
| `workflow_artifacts` | 按研究、运行和关键词查找真实产物 |
| `workflow_artifact` | 分页读取内容，并向对话提供结构化展示 |
| `workflow_chart_preview` | 使用真实 matplotlib 生成图片，向对话提供可预览、下载的图表 |
| `workflow_export` | 导出研究或冻结运行，对话中的任务卡持续更新并提供下载 |
| `workflow_notes` | 读取、保存带真实运行引用的研究笔记 |
| `workflow_plugins` | 发现插件依赖、开关和环境配置状态 |

对话工具记录分别携带 `workflow_view`、`artifact_view`、`task_view`。这些结构化信息独立于给模型的文本截断预算保存。研究室和页面内“问 AI”均可显示对应内容，工作流运行卡可呈现主要图表和最终输出。结果源于实际运行和经完整性检查的工件，不从模型回复中推测生成。

画布定期同步 Agent 或其他窗口保存的新修订、进行中任务和结果；本机有未保存改动时保留草稿并提示合并。显式打开的历史运行保留冻结修订，不自动换成最新实验。

## 插件管理

当前管理八项内置研究能力：研究工作流、数据与产物、实验管理、图表工作台、因子、模型、组合、执行研究。

工作区启停由管理员控制；导航可见性和 Agent 调用偏好按当前用户、当前工作区分别保存。核心研究与数据能力保持启用，可收起导航。插件表同时显示依赖及所选研究环境的配置状态；缺依赖时提供环境设置入口。现有现货、永续、真实资金开关继续由原工作区功能体系管理。

停用前列出受影响研究，包含封装模块内部的依赖。服务器校验 GUI、Agent 和嵌套流程中的能力，停用可阻止新执行；既有历史证据仍能读取，已有任务可取消。关闭 Agent 的数据能力也会阻止其数据读取及依赖该能力的图表调用。停用的工具会从提供给模型的工具目录中移除，执行时继续校验策略。

Agent 验收覆盖实际工具桥接与结构化记录传输，没有消费外部大模型推理额度。研究依赖安装在独立的 `.qa-studio-env` 测试环境，系统 Python 和用户研究数据未修改。代码未提交 Git。
