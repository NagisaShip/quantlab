# QuantLab v 0.1 preview · 个人账户接入教程（只读）

[English](Personal-Account-Integration-Guide.en.md) | [文档索引](README.md) | [返回 README](../README.md)

> 这一步**不是必需的**。没有交易所账户也能完成策略编写、回测、参数优化与实时模拟。
> 只有当你想把“策略模拟结果”和“账户里真实发生的成交”放在一起对照时，才需要接入真实记录。

平台提供两种接入真实记录的方式：

| 方式 | 适合 | 需要提供 | 平台能看到 |
| --- | --- | --- | --- |
| **A. 导入 CSV**（`imported_live`） | 不想给任何 Key；或账户在不支持的交易所 | 交易所导出的成交 / 资金流水 / 余额 CSV | 只有你上传的文件内容 |
| **B. 只读 API Key**（`readonly_live`） | 想定期自动同步 | 一把**只开读取权限**的 API Key | 余额与指定交易对的成交 |
| 官方测试网（`testnet`） | 练习接入流程 | 测试网 Key | 测试网数据，一律标为“测试”，不进入实盘结果 |

以上两种方式都是**只读接入**：只读客户端只实现 GET 请求，不会替你下单。
平台另有独立的「微实盘」通道，默认关闭，只支持已毕业策略的小额现货交易；它与这里的只读账户是两套独立连接。

---

## 平台绝不收集的东西

登录密码、短信 / 邮箱验证码、谷歌验证码、助记词、私钥、网页登录 Cookie。任何页面向你索要这些，都不是本平台。

## 方式 A：导入 CSV

1. 在交易所后台导出成交记录（币安：订单 → 现货订单 → 交易历史 → 导出；OKX：订单中心 → 成交明细 → 下载）。
2. 打开“真实结果 → 实盘对照 → 导入真实记录”，选择记录类型（成交 / 资金流水 / 余额），粘贴或上传文件。
3. 列名会自动识别（中英文常见列名都支持）。识别不了的列，在“字段映射”里指定，例如 `qty ← Executed`。
4. 点击导入。**全有或全无**：只要有一行不合法，整份文件都不入库，并逐行告诉你哪一列有什么问题。

| 记录类型 | 必需字段 | 可选字段 |
| --- | --- | --- |
| 成交 fills | 时间、交易对、方向、数量、价格 | 手续费、手续费币种、订单号、client_order_id、成交号 |
| 资金流水 flows | 时间、币种、金额（正入负出） | 类型、参考号 |
| 余额 balances | 时间、币种、可用 | 冻结 |

数量与价格按十进制精确解析（不经过浮点数）。以 `=`、`+`、`-`、`@` 开头的“公式单元格”会被拒绝，防止 CSV 公式注入。
同一份文件重复导入会被识别（按内容摘要）。

## 方式 B：绑定只读 API Key

### 币安（Binance）

1. 网页版登录 → 头像 → **API 管理** → 创建 API（系统生成）。名称建议写“QuantLab 只读”。
2. 权限**只保留“允许读取”**。不要勾选：现货与杠杆交易、合约、提现、内部划转、万向划转。
3. **IP 访问限制**选“仅限受信任的 IP”，填入本服务的出口 IP（部署者可在服务器上执行 `curl ifconfig.me` 获得）。
4. 复制 API Key 与 Secret Key（Secret 只显示一次）。

### OKX

1. 登录 → 个人中心 → **API** → 创建 V5 API Key。
2. 权限**只勾选“读取”**，不要勾选“交易”“提现”。
3. 绑定 IP 地址（本服务出口 IP）；设置 Passphrase 并记下来。
4. 复制 API Key、Secret Key 与 Passphrase。

### 在平台里绑定

打开“真实结果 → 个人账户 → 绑定只读账户”，三步向导：

1. **选择交易所与环境**：实盘账户（只读）或官方测试网；给连接起个名字。
2. **确认创建方式**：按页面步骤核对，勾选“我已创建只读 Key”。
3. **粘贴并检测**：粘贴 Key（OKX 另填 Passphrase），点击“检测并保存”。平台会依次检查：

| 检查项 | 币安 | OKX | 不通过时 |
| --- | --- | --- | --- |
| 时间同步 | `/api/v3/time` 与本机时间差 < 5 秒 | — | 提示校时（签名会失败） |
| 账户身份 | `/api/v3/account` 返回的 UID（掩码显示） | `/api/v5/account/config` 的 UID | Key 无效，拒绝 |
| 只读权限 | `/sapi/v1/account/apiRestrictions`：现货/杠杆/合约交易、提现、划转均未开启 | `perm` 字段只含 `read_only` | **拒绝且不保存**，告诉你哪项权限开着 |
| IP 限制 | `ipRestrict` | `ip` 字段 | 只警告，不拒绝；强烈建议绑定 |

检测通过后，Key 用**独立主密钥**加密保存为单独的密文文件；数据库与日志里只有 `connection_id`、
Key 掩码（如 `AbCd******wXyZ`）与密文引用，任何接口都不会再返回明文。

### 同步与对照

- 在连接卡片上填写要同步的交易对（如 `BTC/USDT,ETH/USDT`），点击“同步余额与成交”。同步由后台 worker 执行。
- 然后到“实盘对照”：选择一个回测或实时模拟，再选择真实记录来源，生成对照报告。
  报告会说明每笔真实成交是如何归到策略上的：
  `client_order_id` 精确匹配 → 显式映射 → 交易所订单号 → 时间与方向启发式（附置信度）；
  归不上的成交单独列为“未归因”，不会被硬塞进策略结果。

### 撤销

点击“撤销连接”后，平台**立即删除该连接的密文文件**（加密擦除），连接记录只保留掩码用于审计。

> ⚠️ 撤销只删除平台保存的凭证，**交易所侧的 API Key 仍然有效**。请务必到交易所后台删除或禁用这把 Key。

## 没有接入时页面会显示什么

“实盘对照”在没有任何真实记录时显示 **“未接入真实成交”** 空状态，**不会用模拟曲线补位**；
全局横幅也会显示当前模式（回测 / 实时模拟 / 导入记录 / 只读实盘 / 测试网），避免把模拟结果误认为真实收益。

## 常见问题

**检测提示“开启了交易权限，已拒绝”？** 回到交易所后台编辑这把 Key，取消交易权限后重新粘贴；或新建一把只读 Key。

**检测通过但同步不到成交？** 确认填写的交易对与交易所一致（现货，`BTC/USDT` 形式）；币安单次最多回溯 1000 笔，可分多次同步。

**连接显示“已过期 / 被交易所拒绝”？** 多为交易所侧删除了 Key、IP 白名单与服务出口不一致、或 Key 超过有效期。点“重新检测”看具体原因。
