# QuantLab 本地研究桌面

> 新桌面外壳：Tauri 2（`desktop/`）。旧的 pywebview 启动器（`packaging/desktop`）保留但已弃用，
> 只作为回退方案。详见 [桌面端 Tauri 迁移](桌面端Tauri迁移.md)。

## 启动与项目

Windows 安装包提供独立 CPython 和基础研究依赖，不依赖系统 Python，也不需要登录平台账号。运行 QuantLab.exe 后选择项目文件夹；数据和历史保存在该目录的 `.quantlab` 中。重新打开同一目录连接原服务，打开其他目录启动独立实例，原项目任务继续运行。

桌面窗口需要 Windows x64、Microsoft Edge WebView2 Runtime 和系统 .NET Framework。启动器会检测 WebView2，缺失时给出微软官方下载入口和明确原因；离线机器可预装 Evergreen 独立运行时。基础发行版包含 pandas、matplotlib、networkx、scipy、scikit-learn、Excel/Parquet 支持，神经网络 torch/GPU 依赖在项目页按需安装。

源码启动：先安装项目的 `research,desktop` 可选依赖并构建前端，再执行 `python -m quant_agent.local.launcher --project "D:\Research\ProjectA"`。仅当明确启用本地模式时关闭账号及协作 API；账号版原有认证与权限保持原行为。安装器不自动停止当前账号版服务，也不迁移原数据库。

## 数据、环境与权限

设置 → 本机 → 本地项目统一管理文件、Python 环境、任务资源、缓存及模块库；侧栏底部和顶栏齿轮都提供设置入口。桌面窗口提供系统文件/文件夹选择器，浏览器模式可粘贴本机路径。多文件拖入可流式复制导入；大文件推荐引用，避免再次复制。目录可浏览后逐个选择。研究工作流的「直连行情数据源」卡片可联网直接读取交易所公开 K 线（Binance / OKX / Bybit），无需先导入文件；含有该卡片的工作流不能导出为完整离线包，需要离线复现时请改用文件数据源冻结行情。

外部数据需要明确只读授权；可写目录单独授权。CSV/TSV、Excel、Parquet、JSONL 支持有界预览；CSV 编码可指定，文本代码保留前导零。平台不设本地上传统一字节上限，预览、内存运算和图表仍有明确上限。`source.file` 可显式分区读取，超出范围不默默当成完整样本。上传不会覆盖同名旧输入。

引用记录文件指纹。原文件改变、消失或授权撤销会阻断继续把它当成旧数据；重新定位会保留原指纹历史。需要严谨复现时，应复制或冻结原始输入。目录授权约束平台文件入口，不是阻止恶意自定义 Python 的安全沙箱；只运行自己信任的代码。

环境页位于设置 → 本机 → 研究环境（账号模式为设置 → AI → 研究执行环境），显示真实解释器和依赖版本，可发现系统 Python、venv、Conda，检查后切换，或新建研究环境修复依赖。支持在线包索引和本机离线 wheel 目录。安装成功且兼容检查通过后才切换；失败保留旧环境与日志。卡片执行、图表/文件预览、依赖检查和工作流依赖导出共用选定解释器。原专业研究页使用服务解释器，桌面随包基础环境已包含这些依赖。

## 设置、对话项目文件夹与关于窗口

本地项目不再是独立页面：旧链接 `#/local` 会自动跳到设置 → 本机 → 本地项目。设置左侧按「本机 / AI / 开发者」分组，本机模式隐藏账号、工作区、额度、成员与协作类设置；页脚与侧栏底部提供「关于 QuantLab」和设置入口。首次打开一个空项目时窗口落在「设置 → 本地项目」做初始化，项目已有数据后再次启动直接进首页；设置页右上角 × 随时回到首页。

AI 研究室的对话以「项目文件夹」归类。新对话输入框左下角「＋ → 项目文件夹」可以选择已有文件夹、新建文件夹或移出项目；创建后对话归属于该文件夹。新对话默认沿用最近使用的文件夹，本地模式在没有历史文件夹时默认当前项目文件夹名；打开已有对话会记住它的文件夹，供下一次新对话继承。侧栏对话列表按项目文件夹分组，仍可切换按类型分组、重命名、解散与移动对话。

点击左上角 QuantLab 品牌、设置页底部「关于 QuantLab」或账号菜单「关于 QuantLab…」会打开关于窗口（介绍页左上角品牌同样可打开），显示版本、定位、能力边界与开发者入口。

## 会话编排与证据

研究对话右侧“会话栏 → 工作流编排”展示来自结构化工具结果的真实工作流，不根据聊天文字推断执行成功。默认看到完整研究模块，可点击节点查看参数、端口、连接、工件指纹，再逐层展开内部函数；函数代码在独立页面打开。复杂编辑通过“完整画布”继续。

拟议修改、已保存修订、实际运行分别标记。Agent 的 `workflow_propose` 只生成提案和差异，点击保存才产生新修订；修订冲突明确报错。运行记录保留解释器、依赖、源码及输入指纹。模块内部证据须属于本工作区和该父运行，不能拿任意子 ID 读取其他运行。

可将调整后的组合封装为模板。跨项目模块库固定 kind/version/hash；导入包含用户实现包及递归函数定义。内置实现包与当前发行版不一致时拒绝静默替换，需显式升级模板或使用原发行版。`user.asset_<指纹>` 是资产定义的确定性标识，界面标题保留人类可读名称，重复快照不重复造版本。

## Agent 接口与原缺陷

|事项|现有行为|
|---|---|
|D1、D2 执行环境/图表|依赖按选定解释器检测、执行；缺少时给出具体依赖和修复入口|
|D3 实验计划|`plan={"mode":"grid","axes":[{"node":"input","parameter":"max_rows","values":[100,200]}]}`；help experiments 提供 schema 和示例|
|D4 资产快照|紧凑返回完整契约摘要和 definition_ref；通过 workflow_sources 按文件读取源码，避免响应截断|
|D5 工件分页|offset 超出 total 显式报错，等于 total 返回合法空页|
|D6 子运行|workflow_child_evidence 可从 child_run_id 找父运行；help evidence 解释父子关系|
|D7 空工作区自举|workflow_import_data 接收显式表格/CSV 文本；workflow_local_files 仅访问用户已授权的本机路径|
|目录|返回所请求 section 的内容和独立数量，不用空 cards 混淆工作流列表|
|创建工作流|新建路径支持 revision 0，不把 0 当成“缺少参数”|

Agent 文本导入限制为 5000 行或约 2MB，防止把大型文件塞进对话上下文；本地文件入口不受此文本限制。图表的 artifact_hash 来源于实际数据工件，不是资产定义的 sha256。先运行取得工件，或直接用显式小型 data 预览。

## 运行、迁移与恢复

资源页显示 CPU、内存、磁盘和可发现的 NVIDIA GPU，任务可查看或取消。关窗可选择询问、托盘后台、退出；仍有活动任务或环境安装时阻止退出。关闭桌面窗口与停止项目服务分开处理。项目使用实例文件锁，避免同一目录被两个桌面服务同时接管。

异常终止后保留草稿、会话和已写出的证据；未完成的对话/管理操作明确标为中断，运行队列沿用原有租约恢复机制，不声称每类模型调用或外部操作都能从中断的指令位置续跑。

项目快照用 SQLite 一致性备份，排除环境、缓存、会话令牌、密钥和模型服务配置；不递归打包外部符号链接。迁移：解压到新目录，选择该文件夹打开，重新配置模型凭证、选择环境并授权/定位外部引用。卸载应用保留用户项目。

本地 Windows 主密钥使用当前用户 DPAPI 保护并置于项目外，项目导出不携带。换机器/Windows 用户后重新配置凭证。缓存清理只移除可重建的节点缓存，不删输入、图表或运行证据，活动研究期间禁止清理。

独立工作流包保留原有脱离平台执行能力：源码、输入副本、锁定依赖及 wheelhouse。包面向记录的 Python/系统平台，需兼容 Python；桌面包另行自带 Python。需要联网或尚未独立实现的卡片会拒绝冒充完整离线包。
