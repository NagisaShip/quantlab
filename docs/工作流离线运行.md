# 下载后独立运行

在工作流工具栏选择完整离线导出。后台会检查连接，收集精确卡片版本、全部显式输入和传递依赖安装包。完成后下载ZIP。导出构建时需要能获取依赖；下载完成后的安装和运行无需平台、账户或互联网。

ZIP含workflow.json、cards.json、workflow_runtime、files、requirements.txt、requirements.lock、wheelhouse、manifest.json、run.py、setup.bat、run.bat、setup.sh以及说明和卡片规范。manifest记录文件哈希、代码哈希、Python及平台信息，运行前检查内容是否完整。

1. 将完整ZIP解压到可写目录。
2. 准备manifest记录的Python主次版本与相同系统/CPU架构。当前包不内置Python解释器。
3. Windows运行setup.bat，然后run.bat；Linux/macOS运行`sh setup.sh`，再运行`.venv/bin/python run.py`。
4. 无第三方依赖时可直接运行`python run.py`；`python run.py --check`仅检查包哈希与静态连接。
5. 结果写入outputs/runs，工件位于outputs/artifacts。`--target 节点ID`执行指定节点及其上游。

安装脚本只读取包内wheelhouse，使用`--no-index --require-hashes`。不要在运行失败时关闭完整性校验或用“在线补装”掩盖不完整导出；应检查Python/系统是否匹配，或回到平台重新构建。

包内源码可审阅；如要修改计算，先制作开发副本并按卡片版本规范重新生成包。哈希用于完整性检验，不能验证发布者身份。仅运行可信代码。

本次独立运行验收使用明确标注的六行合成数据及逻辑回归链路，验证依赖与运行能力；其数值不是本次作业的实证结果。
