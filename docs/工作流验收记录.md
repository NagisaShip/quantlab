## 使用与限制

重启QuantLab的API与Worker后，从“研究工作流”进入。页面“编写自定义卡片”可创建源码；“更多→代码”查看函数；“复制并自定义”保留原版本。导入CSV后先自检，再运行。首次批量实验会受现有工作区并发与运行配额约束；已成功登记的实验不会因后续登记失败被隐去。

现有默认构建在此Windows环境中遇到esbuild大分块临时文件删除权限错误，因此新增`npm run build:windows`：使用esnext、不压缩，已实际构建并用于浏览器验收；原默认命令保留。该入口面向现代浏览器，生成资源较大，不能当作旧浏览器兼容构建已验证。

现有测试栈有两条Starlette/httpx/anyio弃用提示，不影响本次结果。未通过强制升级或自动修复修改无关依赖。
