# 模块化研究工作台实施方案

本轮不再处理课程作业。目标为人和Agent共用同一模块定义、运行服务和证据，默认使用完整研究模块，按需展开、修改及重新封装。原策略、因子、模型、组合工作台继续保留。

模块契约包含用途、适用条件、语义端口、字段单位和频率、参数说明与来源、预览方式、资源提示、可移植性及执行影响。基础函数集中在独立quantlab_research包；公开卡片包装只负责契约和调用。完整研究以子流程公开接口封装，内部辅助函数不泛滥为卡片。

实现顺序：建立分类目录及常用基础操作；完善语义检查及参数暴露；独立代码工作台复用现有CodeEditor/CodeView/DiffView；图表配置与独立预览；神经网络组件DAG与形状检查及真实执行；原专业资产接入及Agent工具；回归和页面验收。旧卡片版本和历史运行保持兼容。

基础目录覆盖数据整理、时间和样本、拟合/应用变换、统计计量、因子、策略回测、模型、网络、组合风险及展示。学习型变换必须单独拟合并输出变换器。图表展示设置与统计口径分别保存，配置变更仅重跑图表下游。

神经网络外层为研究流程、内层为组件DAG。支持的组件来自共同结构定义，图、形状、参数量和执行一致。任意自定义Python不承诺自动无损转换，无法解析部分明确标为自定义组件。

代码页有文件列表、入口跳转、接口说明、草稿、检查与版本差异，可查看冻结运行源码。公共版本不覆盖；草稿变化通过新版本应用到工作流。平台资产通过来源明确的适配器接入，平台运行能力不假称完整离线实现。

验证以真实输入和数值结果为主，覆盖数据泄漏、语义连接、子流程等价与参数提升、图表样式隔离、组件形状/残差/训练、版本及工作区边界、原工作流回归、前端构建和关键页面。全程不commit。

2026-10-21实施验收：112项后端测试通过，前端类型检查和构建通过；独立代码页面、草稿恢复、组件网络及分层引擎参数表单已完成浏览器检查。递归模板支持8层封装验收，位置及数据用途保持一致。独立运行包已在未安装平台的新环境中仅用随包依赖执行。具体操作、限制及自定义规范见《workflows/模块化研究使用与扩展.md》。原生策略、模型资产的画布接入目前为定义快照及专业页面入口，其完整运行协议仍是明确待扩展部分。
