## 模块边界

平台执行机制位于`quant_agent.workflows`，独立算法包位于`quantlab_supplychain`。算法函数只接收ctx、inputs、params，不访问平台账号或数据库。文件通过ctx.file读取，模型、图和图片通过ctx.save_file输出为带哈希的工件引用。

`prepare`清洗，`alignment`名称实验与约束，`graph`年度图与训练期变换，`models`网络，`train`训练与消融，`evaluate`独立测试，`explain`解释，`publication`打印图表。`catalog.card_sources()`提供本次使用的版本2包装函数。包装函数和多文件算法均进入运行快照。

在其他工作区复用，先使用自己的账号及明确的目标工作区ID执行：

```text
python scripts/register_supplychain.py --url http://127.0.0.1:8000 --email YOUR_EMAIL --workspace WORKSPACE_ID
```

密码交互输入，不通过命令行参数保存。该操作仅注册函数定义，不导入原课题商业数据、不执行训练。重复注册相同源码可复用已有版本，已有版本不可覆盖。算法变更应升级卡片版本，并保留旧运行快照。

## 独立运行包

课题目录的成果文件夹内保存四个包：final为冻结证据再评价，train为从原始CSMAR重新清洗建图训练，lora含基础模型权重与微调链路，time_ablation为严格单步历史消融。包内有运行器、函数、多文件实现、显式资源、requirements.lock及wheelhouse，不依赖QuantLab服务或账号。需要Windows x64与Python3.12解释器；GPU任务另需相容驱动与硬件。包不附带解释器或驱动。

final已在全新venv中以--no-index --require-hashes安装并完整重跑。train已在另一全新venv中从原始数据运行至model_hgnn并重训三种子HGNN。LoRA原始80步训练在平台内完成，完整独立包逐文件SHA256核验通过，未重复进行第二次离线LoRA训练。不要将文件核验说成已经重训。

## 方法限制

CSMAR财务替代WIND；25项候选指标中3项银行授信缺失。未上市2024年目标1019个样本无风险正例，不能计算该子组AUC。板块和制造业雇员规模是研究代理，非完整法定中小企业认证。已更正财务、年度关系及登记快照不足以恢复严格时点信息集，研究限定回顾性状态识别。LoRA直接生成改善但检索Top1下降，图合并依赖独立ID和核验别名。模型分数未校准，解释不代表因果传播。
