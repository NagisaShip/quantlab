# QuantLab v0.1.0-preview.1

2026-10-19

## 个人头像与对话私密默认值更新

- 设置中的头像上传改为真实按钮，上传、更换、恢复默认的显示与禁用状态统一；文件输入框保持隐藏，支持键盘操作和手机换行。
- 新建对话默认私密，可在「设置 → 我的账号 → 个人资料 → 新对话默认可见性」改为工作区成员可见，保存到服务端。
- 手动新建、Agent 新建、完整流程分派和分叉统一登记默认可见性；修改偏好不会追溯更改已有对话。私密对话沿用原有管理员管理权限。
- 可见性登记失败时中止创建，避免数据库异常导致对话意外公开；并发重复登记不覆盖已有共享设置。
- 验证：75 项相关后端回归通过，另补充可见性存储故障时停止创建的回归；2 项真实浏览器验收通过，前端生产构建与静态检查通过。

## 修复与改进

- 修复用户主页回测展示绕过关联策略可见性过滤的问题；摘要、指标、计数与入口统一过滤。策略成果归属使用稳定用户 ID / 所有者记录，不再用显示名推断。
- Mermaid 在固定定位的临时容器中渲染，加载期间不会撑长页面；切换主题后重新绘图。修复普通流程图 PNG 标签导出、Sankey 引号 CSV 节点及占位符冲突。
- 群聊回复默认补充对方提及，回复 Bot 也可直接输入；Bot 快捷选择防重复插入，重复提及只调度一次回复，Agent 消息禁止再次触发 Bot。
- 群消息落库后立即返回，Bot 在后台分别发送回复；原消息和下一条消息无需等待模型完成。现有消息轮询负责接收 Bot 回复。
- 引用菜单改为向上定位，消除全局向下菜单样式冲突并限制高度，避免聊天页变长。
- 策略广场评论整合为聊天式输入面板，提供 Qmoji、Emoji、成员及 Bot 快捷输入，Enter 发表、Shift+Enter 换行。
- 对话列表在空闲时也自动刷新，Agent 主动创建的新对话无需手动刷新。置顶标记改为 SVG 图标。
- 单独优化未登录页：保留现有分屏结构，允许短屏内容自然延伸，移除第三屏图表的嵌套裁切和功能演示图表的高度裁切，调整卡片间距及窄屏布局。
- 主页展示支持按板块自动展示最新成果或手动勾选具体因子、策略、回测、模型、模拟记录；按勾选顺序展示，复用指标网格和收益曲线组件。回测/模拟曲线最多 240 点，提供基准对照，选择不扩大任何权限。
- 个人主页优化资料头部、成果导航、数据卡片与窄屏布局。
- 我的账号改为分区卡片布局，支持上传本人头像、预览、保存、恢复默认；PNG/JPEG/WebP/GIF 限 2 MB，校验文件所有权与工作区。头像在账号、个人主页、群聊与广场同步显示。
- 收窄表格容器，宽表格在自身区域横向滚动；手机回测详情的面板、图表与操作区避免裁切，保留表格移动卡片展示。
- 关注和建私聊使用数据库冲突处理，避免并发互关产生重复记录。

## 容量口径

回测记录硬上限依据服务器磁盘**总容量**的 20% 折算，并与 100,000 单位取较小值，再尊重管理员设置的更低上限；不是按剩余可用空间计算。独立 mock 测试覆盖小盘、大盘、容量读取失败和管理员更低配置。

## 升级

保持原部署方式，更新源码并重新构建前端、重启 API 与 worker。头像复用工作区资料存储，无需新增数据库迁移；旧资料与现有展示配置保留。Bot 后台回复在 API 进程内执行，服务重启可能中断尚未完成的回复。
