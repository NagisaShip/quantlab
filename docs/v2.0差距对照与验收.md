# plan v2.0 差距对照与验收

对照 2026-10-12 版 `plan.md` 的总体判断：“现有代码是一个单机单用户的量化研究工具”。
下表列出每条差距的处理结果、实现位置与守护它的测试。测试路径均在 `tests/` 下，
当前 **473 项测试通过、1 项在 Windows 上按平台跳过**（详见 `docs/测试报告.md`）。

> 复核补充：一轮"声称 vs 实现"的复核发现下列条目原先只是**文本上**成立，
> 已在本轮补齐为真实实现，并各自补了用例（集中在 `tests/test_protocol_v2.py`）：

## 三、刻意保持的边界

- **不做真实下单**。plan 把真实执行留给用户自己的执行器；平台只提供目标仓位信封与校验参考实现（`live/envelope.py`）。
- **不补算停机期间的成交**（实验三口径）。恢复后停机期间的 bar 只推进数据，只在最新一根上调用策略。
- **合成行情明确标注**，不能作为策略结论；横幅显示“合成行情”。
